你好，我是 **ccjlovewsy**，欢迎来到我的个人技术博客。这里主要用来**记录学习与开发中的点滴**——把踩过的坑、读过的源码、搭过的东西整理成文字，既是给自己的复盘，也希望对偶然路过的你有所帮助。

## 这里写什么

- **Kotlin / Android**：编译流水线、跨平台实践等工程问题，比如 [Kotlin/Native 编译全流程解析](/posts/kotlin-native-compile-pipeline/)
- **源码阅读**：带着问题啃源码，输出可复现的分析过程，例如 [Logging 源码精读](/posts/logging-source-reading-interactive/)
- **博客搭建**：Jekyll + Chirpy 主题的折腾记录
- **随笔**：偶尔写点生活与思考

## 如何使用本站

- 顶部搜索图标可全文检索站内文章
- [分类](/categories/) 与 [标签](/tags/) 页按主题浏览，[归档](/archives/) 按时间线回溯
- 右侧面板会展示**最近更新**与**热门标签**，方便快速找到新内容
- 订阅 [RSS](/feed.xml) 可以在新文章发布时收到推送

> 文章底部已开启评论（Giscus），欢迎用 GitHub 账号留言交流；也可以到我的 [GitHub 主页](https://github.com/ccjlovewsy) 找我。
